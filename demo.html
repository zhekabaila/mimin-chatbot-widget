Mimin Chatbot Widget React Demo

🚀 Fitur React Version

  • ✅ React Hooks untuk state management
  • ✅ TypeScript untuk type safety
  • ✅ Tailwind CSS untuk styling
  • ✅ Component-based architecture
  • ✅ Props untuk configuration
  • ✅ Event handlers React-style

📦 Struktur Komponen

src/ ├── components/ │ ├── ChatWidget.tsx # Main widget component │ ├── ChatHeader.tsx # Header component │ ├── ChatInput.tsx # Input component │ ├── Message.tsx # Message components │ └── CallWindow.tsx # Call window component ├── types/ │ └── index.ts # TypeScript interfaces ├── services/ │ └── api.ts # API service └── utils/ └── styleInjector.ts # Style injection

💻 Cara Penggunaan

1. Import Component

import { ChatWidget } from './components/ChatWidget'; import type { ChatbotConfig } from './types';

2. Setup Configuration

const config: ChatbotConfig = { theme: { button: { backgroundColor: "#ffffff", textColor: "#0096a2", tooltip: "Ask Assistant" }, chatWindow: { backgroundColor: "#0096a2", title: "AI Assistant", width: "350px", height: "600px" } } };

3. Render Component

function App() { const handleSendMessage = (message: string) => { console.log('Message:', message); }; return ( <div className="App"> <ChatWidget config={config} onSendMessage={handleSendMessage} /> </div> ); }

🔄 Perbedaan dengan Vanilla JS

  • State Management: React hooks vs DOM manipulation
  • Event Handling: React event handlers vs onclick attributes
  • Styling: Tailwind + inline styles vs template literals
  • Type Safety: Full TypeScript support
  • Component Structure: Modular React components

🎯 Keuntungan React Version

  • 🔥 Better Performance: Virtual DOM optimization
  • 🧩 Reusable Components: Modular architecture
  • 🔒 Type Safety: Full TypeScript integration
  • 🎨 Modern Styling: Tailwind CSS integration
  • ⚡ Hot Reload: Fast development experience
  • 📱 Responsive: Mobile-first design

🔖 Styling Unik dengan Prefix Tailwind CSS

Catatan: Fitur prefix Tailwind CSS (misal: mimin-) belum digunakan pada versi ini.
Semua class Tailwind pada widget ini masih menggunakan class default tanpa prefix.
Fitur prefix akan tersedia pada versi berikutnya untuk menghindari bentrok style dengan website client.
